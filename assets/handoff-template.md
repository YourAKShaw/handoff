# Session handoff template

Copy everything below the line into `HANDOFF.md` at the repository root and replace each `<…>` with real content. Follow [the handoff format](../references/handoff-format.md); delete any guidance line you do not need.

---

```markdown
# Session handoff

Read this first in every new session; rewrite it at the end of a session when asked for a handoff.

Last updated: <YYYY-MM-DD>

## Goal right now

<The user's current aim in two to five lines.>
<Standing constraints: what must not change, branches not to touch, approvals required.>
<Links to the source documents: brief, issue, spec.>

## Where things stand

- Branch: `<branch>` (remote `<remote>`).
- Done: <one or two sentences, with a pointer to where the detail lives>.
- Checks: <command and result of the last checks actually run, or "not run this session">.

## Next steps

1. <Most important action — file or command to start from, and what to do.>
2. <Next action.>
3. <Next action.>

## Open questions

- <Decision waiting on the user or someone else.>

## Gotchas

- <Environment or process trap a new session would otherwise hit, and how to avoid it.>
```
